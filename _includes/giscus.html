Comments Setup Needed

This blog supports comments and likes using Giscus. To enable them:

  1. Make your GitHub repository public.
  2. Enable Discussions in your repository settings.
  3. Install the Giscus GitHub App on the repository.
  4. Visit giscus.app, enter your repository URL, and copy the generated repo_id and category_id.
  5. Add them to your _config.yml file.
